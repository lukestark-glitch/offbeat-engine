# Handoff – Offbeat Engine

**Fertig**
- Sechs Modi (Kick, Bass, Hat, Stab/Lead, Pad, Riser) mit 13 Presets.
- Eigene Oberfläche im Rave/Tuning-Look mit Zahleneingabe und JSON zum Kopieren/Einfügen.
- Kick Attack.
- Octave und Tempo-Fallback (Host-Tempo / BPM).
- Gemeinsamer Baukasten für die Familie (`plugin/OffbeatKit.hpp` u. a.).
